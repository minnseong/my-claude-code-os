## 1. XP & 레벨 시스템

### 1-1. XP 획득 규칙

| 행동 | XP |
|------|----|
| 루틴 체크 1개 | +10 XP |
| 하루 루틴 전체 완료 | +50 XP 보너스 |
| 7일 스트릭 달성 | +100 XP 보너스 |

### 1-2. 중복 적립 방지

- 동일 루틴 체크로 XP는 **1일 1회**만 적립
- 체크를 취소하면 해당 XP는 차감
- 전체 완료 보너스는 해당 날짜에 하루 1회만 지급

### 1-3. 레벨 구간

| 레벨 | 필요 누적 XP | 칭호 |
|------|------------|------|
| 1 | 0 | 습관 새싹 |
| 2 | 100 | 루틴 수련생 |
| 3 | 300 | 습관 전사 |
| 4 | 700 | 루틴 마스터 |
| 5 | 1,500 | 전설의 실천가 |

- 레벨업 시 즉각 알림 (애니메이션 + 메시지)
- 레벨은 내려가지 않는다 (XP가 차감돼도 최저 레벨 유지)

## 2. 스트릭 시스템

### 2-1. 스트릭 증가 조건

- **당일 스케줄된 루틴을 100% 완료**한 날이 연속되면 스트릭 +1
- 스케줄된 루틴이 없는 날(예: 수요일 루틴 없음)은 **스트릭에 영향 없음** (건너뜀)

### 2-2. 스트릭 초기화 조건

- 스케줄된 루틴이 있는데 **하나라도 미완료로 하루가 지나면** 스트릭 0 초기화
- 자정 이후 체크 취소로 인해 완료율이 100% 미만이 되면 즉시 초기화

### 2-3. 스트릭 보호권 (Phase 3)

- 스트릭 보호권 사용 시 1회에 한해 초기화를 막는다
- 보호권은 구매 또는 미션 보상으로 획득

### 2-4. 표시

- 메인 화면 상단에 스트릭 수 표시 (불꽃 아이콘 + 숫자)
- 7일·30일·100일 달성 시 특별 뱃지 자동 부여

## 3. 뱃지 시스템

### 3-1. 뱃지 목록 (9종)

| 뱃지 | 획득 조건 | 아이콘 |
|------|---------|--------|
| 첫 발자국 | 첫 루틴 체크 | 👣 |
| 일주일의 기적 | 7일 스트릭 | 🔥 |
| 한 달의 힘 | 30일 스트릭 | 💪 |
| 완벽주의자 | 하루 루틴 100% 완료 10회 | ✨ |
| 다양한 도전 | 5개 이상 루틴 동시 운영 | 🌈 |
| 이른 새벽 | 오전 6시 이전 체크 | 🌙 |
| 꾸준한 심장 | 100일 스트릭 | ❤️ |
| 미션 마스터 | 일일 미션 30회 완료 | 🏆 |
| 보스 킬러 | 주간 보스 챌린지 3회 클리어 | ⚔️ |

### 3-2. 뱃지 정책

- 뱃지는 한 번 획득하면 취소되지 않는다 (루틴 삭제, XP 차감과 무관)
- 획득 시 즉각 팝업 알림
- 마이페이지에 획득한 뱃지/미획득 뱃지 모두 표시 (미획득은 잠금 상태)

## 4. 일일 미션

### 4-1. 미션 생성 규칙

- 매일 자정에 자동으로 3개의 미션 생성
- 미션은 현재 사용자의 루틴과 레벨을 기반으로 선택
- 미완료 미션은 다음 날 사라짐 (누적 불가)

### 4-2. 미션 유형

| 유형 | 예시 |
|------|------|
| 체크 수 | "오늘 루틴 3개 완료하기" |
| 특정 시간대 | "오전 중 루틴 체크하기" |
| 연속 | "어제에 이어 오늘도 전체 완료하기" |

### 4-3. 미션 보상

- 일반 미션 완료: +30 XP
- 모든 일일 미션 완료: +80 XP 추가 보너스
- 미션 보상 XP는 루틴 체크 XP와 별도 적립

## 5. 주간 보스 챌린지

### 5-1. 보스 등장 규칙

- 매주 월요일 자정에 주간 보스 등장
- 일요일 자정에 미클리어 시 사라짐

### 5-2. 보스 공략 방법

- 해당 주에 루틴 체크할 때마다 보스 HP 감소
- HP 계산: 총 HP = (이번 주 스케줄된 루틴 수) × 10
- 70% 이상 달성 시 클리어

### 5-3. 보스 클리어 보상

| 달성률 | 보상 |
|--------|------|
| 70% ~ 89% | +150 XP |
| 90% ~ 99% | +250 XP + 랜덤 뱃지 힌트 |
| 100% | +400 XP + 스트릭 보호권 1개 |

## 6. 게이미피케이션 연동 규칙

> 루틴 체크와 게이미피케이션 이벤트의 실행 순서

```
루틴 체크
  → XP 적립 (±10)
  → 전체 완료 여부 확인 → 완료 보너스 XP (+50)
  → 스트릭 갱신
  → 뱃지 획득 조건 확인
  → 일일 미션 달성 확인
  → 주간 보스 HP 갱신
  → 레벨업 확인 → 레벨업 시 알림
```

- 위 순서는 단일 트랜잭션 내에서 처리한다
- 어느 한 단계가 실패해도 체크 자체는 롤백하지 않는다 (XP/뱃지만 재시도)
